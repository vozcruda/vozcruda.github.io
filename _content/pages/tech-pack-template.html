What is in the template

SheetWhat you fill inWhy the factory needs it
1. CoverBrand, style name and number, drop, version, sizes, quantity, contactEveryone refers to the same garment and version
2. Flat sketchesFront and back drawings with numbered calloutsShows what is intentional, like a dropped shoulder
3. Size chartPoints of measure for each size, with tolerancesFinished garments are checked against it
4. Bill of materialsFabric, GSM, composition, rib, thread, labels, trimsAccurate quotes and the right materials in bulk
5. ConstructionSeam types, stitch types, hem widths, finishesStops quiet changes between sample and bulk
6. ArtworkPrint or embroidery method, file, size, placement, coloursRepeatable placement across sizes and reorders
7. Labels and packingNeck and care labels, hang tags, fold, polybag, cartonsAvoids last-minute dispatch delays
8. Order sheetQuantity per colour and size, delivery date and addressLets the factory plan fabric and production

How to fill it in

  1. Start with the cover. Give the style a number (for example TS-001) and call the first issue V1.
  2. Measure a garment you like for the size chart, laid flat, in centimetres. Grade the other sizes from it and add a tolerance for each point.
  3. Be specific in the bill of materials. Write "100% combed cotton single jersey, 240 GSM, bio-washed", not "cotton". Our fabric and GSM guide explains the terms.
  4. Measure placements. "Top of print 8 cm below front neck seam" instead of "print on chest".
  5. Attach artwork as separate files, not only as pictures inside the tech pack.
  6. Send it with your quantity and target date so the factory can quote properly, then review each sample against it and issue V2 with changes. See the sampling process.
